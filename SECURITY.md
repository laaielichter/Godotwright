# Security

Report a vulnerability privately through
[GitHub security advisories](https://github.com/laaielichter/Godotwright/security/advisories/new).
Please do not open a public issue for it.

Godotwright reads Godot projects and can run Godot headless on them (`check`), so treat
projects from people you do not trust like any other code you run. Opt-in sharing is
described in [PRIVACY.md](PRIVACY.md).
