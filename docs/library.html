Asset library

1000 base models for Godot 4, built from code.

Every model below is a parametric spec that builds a clean .glb (UVs, tangents, textures with normal maps, a node per part, pivots on hinges and hubs), passes the model lint and the check against what the thing is, and loads in Godot 4.7, all tested. A coding agent builds one by its id, changes its parameters, or copies its spec as the start of its own model.

godotwright model library "eiken stoel"                      # search, English or Dutch
godotwright model build furniture/dining-chair-oak-ladder -o chair.glb --collision convex
godotwright model library furniture/dining-chair-oak-ladder --spec > my-chair.json

Pictures: rendered in Godot 4.7 (Compatibility renderer, AgX, one sun), the model as built, nothing added. 10 of 1000 shown with a picture.
