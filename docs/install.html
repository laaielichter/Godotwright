Install

Add Godotwright to your agent.

One step for each client. Everything runs on your machine; the first start downloads the package from npm. Needs Node.js 22.12 or newer.

Claude Code

Claude Code plugin

The plugin adds the MCP server and three skills: /godotwright:review (review and fix), /godotwright:port (Godot 3 to 4) and a Godot workflow Claude follows on its own. Type this in Claude Code:

/plugin install godotwright --marketplace laaielichter/Godotwright

On a Claude Code older than 2.1.275, add the marketplace first:

/plugin marketplace add laaielichter/Godotwright
/plugin install godotwright@godotwright

Only the MCP server, without the skills:

claude mcp add godotwright -- npx -y godotwright mcp --tier premium
Claude Desktop

Claude Desktop one file

No terminal needed: download the bundle, open it, and Claude Desktop installs it. Choose your Godot project folder in the settings it shows.

Download godotwright.mcpb

In Claude Desktop you can also drag the file onto Settings > Extensions. The bundle comes with every release from 0.2.0.

Cursor

Cursor one click

Click the button with Cursor installed and confirm the install in Cursor.

Add to Cursor

Or add it to ~/.cursor/mcp.json (all projects) or .cursor/mcp.json (this project):

{
  "mcpServers": {
    "godotwright": {
      "command": "npx",
      "args": ["-y", "godotwright", "mcp", "--tier", "premium"]
    }
  }
}
VS Code

VS Code one click

For GitHub Copilot agent mode. Click a button with VS Code installed and confirm the install.

Install in VS CodeVS Code Insiders

Or from a terminal:

code --add-mcp '{"name":"godotwright","type":"stdio","command":"npx","args":["-y","godotwright","mcp","--tier","premium"]}'
Codex

Codex

codex mcp add godotwright -- npx -y godotwright mcp --tier premium

Or in ~/.codex/config.toml:

[mcp_servers.godotwright]
command = "npx"
args = ["-y", "godotwright", "mcp", "--tier", "premium"]
startup_timeout_sec = 30 # the first npx run downloads the package
Gemini CLI

Gemini CLI extension

The extension installs the MCP server; update it later with gemini extensions update godotwright.

gemini extensions install https://github.com/laaielichter/Godotwright

Or add the server to ~/.gemini/settings.json:

{
  "mcpServers": {
    "godotwright": {
      "command": "npx",
      "args": ["-y", "godotwright", "mcp", "--tier", "premium"]
    }
  }
}

Zed

Zed

Add it to your Zed settings.json:

{
  "context_servers": {
    "godotwright": {
      "source": "custom",
      "command": "npx",
      "args": ["-y", "godotwright", "mcp", "--tier", "premium"],
      "env": {}
    }
  }
}
Any other MCP client

Any other MCP client

Godotwright is a standard MCP server over stdio. Most clients take this:

{
  "mcpServers": {
    "godotwright": {
      "command": "npx",
      "args": ["-y", "godotwright", "mcp", "--tier", "premium"]
    }
  }
}

It is also listed in the official MCP Registry as io.github.laaielichter/godotwright.

Start your agent in the Godot project folder, or pass --project <path>. These setups use --tier premium (full detail). For small, cheap models use --tier cheap: shorter output and step-by-step instructions. check, test, play and screenshot need Godot 4.7; set GODOT to its path if it is not found.
