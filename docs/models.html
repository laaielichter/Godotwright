3D models from code

59 ready-made models for Godot 4.

A coding agent can build every model on this page with one command, change its size and parts, look at it as text, and check it: clean .glb files with textures and normal maps for brick, tiles, wood, bark, leaves and more, a node per moving part and the pivots Godot scripts expect. No Blender, no art tool, the same bytes every time.

Install in 1 minute Works with small, cheap models too

Real renders of the default model of each kind in three.js, with the textures and materials in the .glb and nothing added. They are game-ready base models, meant to be refined, not hand-sculpted art.

How an agent builds a model

  1. Identify. godotwright model identify "a tractor" says what a thing is: its parts, typical size, variants, pivots and what to anticipate. English or Dutch, typos and descriptions work.
  2. Build. godotwright model build car --set width=1.9 -o car.glb from a ready-made kind, or from your own JSON spec of named parts.
  3. View. godotwright model view car.glb draws front, side and top views as text, with a table of the parts, for agents that cannot see a picture.
  4. Check. godotwright model lint car.glb --archetype car scores geometry, materials and performance, and checks it is what it should be: required parts, pivots, wheel axes, size, direction.

FAQ

Do I need Blender or Godot installed?

No. Models are built and checked by Godotwright itself. Godot only loads the result when you open the .glb in your project.

Can I change the models?

Yes. Every kind has parameters with ranges (godotwright model kinds lists them), and every recipe is a JSON spec you can copy and edit.

Can a cheap model like Haiku or a Flash model do this?

Yes, with limits. In a small test, six Haiku agents each built a recognisable model, but they worked blind; that is why model view and a check for loose parts exist. See the write-up.

How good are they?

They are correctly scaled, textured low-poly models with the right parts and pivots: real windows and frames, bevelled edges, glowing lamps, brick, tiles, wood and foliage with normal maps. Not sculpted art, but a solid start that an agent can refine, and models that load and animate in Godot without fixing.
