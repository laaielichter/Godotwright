Godot 3 to Godot 4

Port your project with the real Godot 4 API.

Find old syntax and names before they become runtime surprises. Godotwright reviews GDScript against its bundled Godot 4.7 reference and gives replacement hints; it does not convert your project automatically.

Review a project you are porting

Back up or commit your Godot 3 project first, then follow the official Godot migration guide. Use Node.js 22.12 or newer to review the project without installing Godot or configuring a model/API key:

npx -y godotwright review /path/to/your-project

Pass the directory containing project.godot. Follow each finding's file and line number, update the code, and run the review again. Look up a replacement with npx -y godotwright api CharacterBody2D. A review is static analysis; it does not replace opening the converted project in the matching Godot version and testing gameplay. Native validation with godotwright check requires Godot 4.7.

GDScript syntax changes

These are the Godot 3 forms recognized by the review's api/godot3-syntax rule. Adapt annotations and RPC options to your project's behavior.

  1. export var is @export var in Godot 4.
  2. onready var is @onready var in Godot 4.
  3. tool is @tool in Godot 4.
  4. setget is gone in Godot 4; use var x: T: set = _set_x, get = _get_x or set()/get blocks.
  5. yield() is await in Godot 4, e.g. await get_tree().create_timer(1.0).timeout.
  6. PackedScene.instance() is instantiate() in Godot 4.
  7. network keywords are @rpc(...) annotations in Godot 4.
  8. funcref() is a Callable in Godot 4: object.method or Callable(object, "method").
  9. connect("signal", target, "method") is signal_name.connect(target.method) in Godot 4.
  10. .method() super calls are super.method() in Godot 4.

APIs that moved

Use the new owner or property. Choose the getter or setter appropriate to the original access. Timestamp APIs differ in units: Time.get_unix_time_from_system() returns seconds, so preserve any required milliseconds conversion when replacing OS.get_system_time_msecs().

Keep reviewing as you migrate

A clean static report is not a guarantee that the port is complete. Check scenes, resources, physics and rendering in Godot, and play-test each migrated feature. See all Godotwright tools and the official migration guide for the engine changes.
