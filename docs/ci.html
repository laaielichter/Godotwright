GitHub Action · Godot 4.7

A Godot check on every pull request.

The Godotwright receipt reviews the GDScript and scenes in a pull request, loads them with a checksum-verified Godot, runs your GUT or GdUnit4 tests and scenarios, and posts one table as a comment, updated on the next push. No editor, no GPU, and the job fails when a step fails.

Set it up in 2 minutesOn the GitHub Marketplace

Set it up

Save this as .github/workflows/godotwright.yml in your game’s repository. That is all.

on: pull_request
permissions: { contents: read, pull-requests: write }
jobs:
  receipt:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
      - uses: laaielichter/godotwright@v0.5.0
        with: { comment: "true" }

For a review only, which needs no Godot download, add review-only: "true". Without comment, the receipt goes to the job summary only, and the job needs just contents: read.

The four steps

  • review: a score from 0 to 100 for api, performance, quality and structure, without Godot. It catches Godot 3 code, methods and signals that do not exist in Godot 4.7, missing $Node paths, scene connections to missing methods, unknown input actions and per-frame lookups, each as file:line with the fix.
  • check: Godot imports the project and loads every script and scene headless; each error comes back once, runtime errors with their GDScript call chain.
  • test: your GUT or GdUnit4 tests, headless; only what failed is shown.
  • scenarios: JSON files in .godotwright/scenarios/ that run a scene, play input into it and check what the game did, for example "Hero.position.x >= 100 @ 25".

Findings inline, or a plain review

To see each finding on its line in the pull request, upload the review as SARIF to GitHub code scanning (needs security-events: write and code scanning turned on):

- run: npx --yes godotwright@0.5.0 review . --sarif > godotwright.sarif || true
- uses: github/codeql-action/upload-sarif@v4
  with:
    sarif_file: godotwright.sarif

Or fail a build on errors or a low score, in any CI that has Node.js 22.12 or newer:

npx --yes godotwright@0.5.0 review . --min-score 80

FAQ

Does it need a GPU or the Godot editor?

No. It downloads a checksum-verified Godot 4.7 for Linux and runs it headless on a standard GitHub runner. With review-only it needs no Godot at all.

Does it send my code anywhere?

No. Everything runs on your own runner. The only thing it posts is the receipt, as a comment on your pull request, when comment is true.

My Godot project is in a subfolder.

Set path to the folder that holds project.godot, or to any path inside it.

Will it fail on my existing code?

It fails when a step has errors. Start with review-only, fix the errors (godotwright fix does the mechanical ones), then turn on the Godot steps. A finding you think is wrong is worth an issue.

Does it work with C#?

No. The review reads GDScript and scenes, and the action downloads the standard Godot build, without .NET.
